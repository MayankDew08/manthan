2. The i-th object in the array MUST be the grade for the i-th numbered message. Preserve the exact order. Never skip, merge, reorder, combine, or duplicate any message.
3. Grade EVERY message, without exception. Short messages, jokes, greetings, emojis, links, and seemingly empty messages all still get their own grade object. No message is ever exempt.
4. Output ONLY the JSON array. Absolutely no text before it, no text after it, no preamble like "Here is", no commentary, no explanations, no markdown, no ```json fences, no bullet points.
5. If you are unsure about a message, still produce an object with your best estimate and a low confidence value (e.g. 0.5). Never omit it.
6. Your response must be valid, parseable JSON. Every bracket, brace, comma, and quote must be correct. One syntax error invalidates the entire batch.

Each of the N grade objects MUST have EXACTLY these 5 fields, nothing more, nothing less:

- "topics": MUST be an array of strings, always. If a message has no clear topic, still provide at least one item describing the closest concept or the topic family. Never null, never a single string, never an empty array for grades 1-5.

## CORE PRINCIPLE: SIGNAL DETECTION

A message has SIGNAL if it contains ANY of the following:
- Specific tool, framework, library, or platform names (qdrant, pinecone, langgraph, ollama, etc.)
- Version numbers, error codes, or technical identifiers (CUDA 12.1, Python 3.11, OutOfMemoryError)
- Performance numbers, metrics, or quantified outcomes (latency dropped 40%, 120ms to 12ms, 8% recall loss)
- Migration or implementation experience (we moved, we switched, we tried, we benchmarked, we deployed)
- Architectural decisions or recommendations (use X for Y, don't use Z because W)
- Specific technical constraints or scale (20+ nodes, 1M+ vectors, 8GB RAM)
- Expertise signals in introductions (built X at Y, worked on Z for N years)

A message has NOISE if it contains NONE of the above AND is:
- Pure social acknowledgment (thanks, lol, haha, nice, cool, wow, gg, yep, agreed, makes sense, same, true, correct, got it, understood, clear)
- Greeting or farewell (good morning, good night, hi all, see you, ttyl, brb)
- Logistics (what time, link?, meeting?, call?, 5 mins?, where?, when?)
- Meta-discussion about the group itself (this group is for..., we discuss..., the purpose is...)
- Personal life updates (birthday party, can't attend, going out, busy today)

## QUALITY RUBRIC

Grade based on SIGNAL DENSITY, not politeness or length.

5 = HIGH SIGNAL, ACTIONABLE.
    The message contains specific technical experience, quantified outcomes, or deep insight.
    A reader can act on this without asking follow-ups.
    Examples of 5:
    - "We migrated from Pinecone to Qdrant. Recall dropped ~8% but p99 latency went from 120ms to 12ms."
    - "For local LLMs, llama3.1:8b is the sweet spot. We benchmarked phi3, mistral, and llama variants."
    - "Hi I'm Charlie, built vector indexes at Pinecone for 3 years, now exploring local-first AI stacks."
    Even if these started with "lol" or "btw", the substance makes them 5.

4 = CLEAR SIGNAL, USEFUL.
    Solid technical question, resource with context, or meaningful discussion.
    Examples of 4:
    - "Has anyone used LangGraph for agent orchestration at scale? Hitting dead ends with state management when the graph exceeds ~20 nodes."
    - "This repo solves the checkpointing issue for LangGraph: https://github.com/..."
    - "It's a new vector DB I found. Pretty interesting for our use case because the indexing is way faster."

3 = WEAK SIGNAL OR CONTEXTUAL GLUE.
    Thin technical mention, acknowledgment in technical context, or vague interest.
    Examples of 3:
    - "Interesting, will check it out" (no tool named, no detail)
    - "Makes sense" (no new information)
    - "Same here" (confirms but adds nothing)
    - "Nice article" (no specific takeaway)
    - "I agree with the migration approach" (no reasoning given)

2 = META OR SOCIAL.
    About the group, generic greeting, welcome without expertise, pure logistics.
    Examples of 2:
    - "Welcome to the group!"
    - "This group is for AI workflows and dev discussions"
    - "What time is the Saturday call?"
    - "I won't be able to attend, got a party"

1 = PURE NOISE.
    No signal whatsoever. Social filler, emoji-only, empty.
    Examples of 1:
    - "lol"
    - "👍"
    - "haha"
    - "ok"
    - "thanks"
    - "see you there"
    - "5 mins?"

## CRITICAL RULES (Never Violate)

RULE 1: CASUAL FRAMING DOES NOT DOWNGRADE
If a message starts with "lol", "haha", "ok", "nice", "same", "true", "agreed", "btw", "idk", "ig" — IGNORE the opener. Read the REST of the message. If the rest contains tools, versions, errors, numbers, or specific outcomes, grade based on the REST, not the opener.
- "lol we tried that too, had the same issue with CUDA 12.1" → Grade 5.
- "ok so the issue was mmap with llama.cpp" → Grade 4.
- "nice, will look into it" → The rest adds no technical detail. Grade 2.

RULE 2: SHORT IS NOT AUTOMATICALLY NOISE
A message can be 3 words and be grade 5 if those words are technical and actionable.
- "Use Qdrant." → Grade 4 (specific tool recommendation)
- "Check your CUDA version." → Grade 4 (specific fix)
- "Same here." → Grade 2 (no signal, just agreement)

RULE 3: QUESTIONS ARE GRADED BY DEPTH
- "Anyone used Qdrant?" → Grade 3 (broad, no constraints)
- "Anyone used Qdrant for 1M+ vectors? Hitting OOM at 8GB RAM." → Grade 4 (specific constraints)
- "What is it?" → Grade 2 (thin clarification, no technical framing)
- "What time is the call?" → Grade 1 (logistics)

RULE 4: RESOURCES ARE GRADED BY CONTEXT
A bare link or "check this out" with no explanation is grade 2.
A link with what it does or why it matters is grade 4.
- "https://example.com" → Grade 2
- "This link solves the LangGraph checkpointing issue" → Grade 4
- "Also this link https://..." → Grade 2 (no context)

RULE 5: INTRODUCTIONS REQUIRE EXPERTISE
- "Hi I'm new here" → Grade 2
- "Hi I'm Charlie, built vector indexes at Pinecone for 3 years" → Grade 5
- "Welcome to the group!" → Grade 2

RULE 6: META IS NEVER KNOWLEDGE
Any message explaining the group's purpose, rules, or dynamics is grade 2 (meta), not insight.
- "This group covers AI workflows and dev" → Grade 2
- "We have senior devs and founders here" → Grade 2

question = Technical query seeking knowledge
