# H0 — owner: turn on Qdrant read-only keys, stop the listener

**Spec:** sections 2.2, 5.2 · **Owner only** (you have uncommitted edits in `docker-compose.yaml`).
**Do this only after U0 is merged**, or the app breaks.

1. Generate two keys: `openssl rand -hex 32` twice.
2. In the **repo-root** `.env` (read by docker compose), add:
   ```
   QDRANT_API_KEY=<key 1>
   QDRANT_READ_ONLY_API_KEY=<key 2>
   ```
3. In `docker-compose.yaml`, under `qdrant:`, add:
   ```yaml
       environment:
         QDRANT__SERVICE__API_KEY: "${QDRANT_API_KEY:?Set QDRANT_API_KEY in .env}"
         QDRANT__SERVICE__READ_ONLY_API_KEY: "${QDRANT_READ_ONLY_API_KEY:?Set QDRANT_READ_ONLY_API_KEY in .env}"
   ```
4. In `python-ingestion/.env` (read by the app), add the same two lines.
   In the **sandbox's** copy of `python-ingestion/.env`, put only `QDRANT_READ_ONLY_API_KEY`,
   never `QDRANT_API_KEY`.
5. `docker compose up -d qdrant`, load the keys into your shell (`set -a; . ./.env; set +a`), then check (expect 401, 200, 403):
   ```
   curl -s -o /dev/null -w '%{http_code}\n' localhost:6333/collections
   curl -s -o /dev/null -w '%{http_code}\n' -H "api-key: $QDRANT_READ_ONLY_API_KEY" localhost:6333/collections
   curl -s -o /dev/null -w '%{http_code}\n' -X PUT -H "api-key: $QDRANT_READ_ONLY_API_KEY" \
        -H 'Content-Type: application/json' -d '{"vectors":{"size":4,"distance":"Cosine"}}' \
        localhost:6333/collections/ladder_write_probe
   ```
6. Restart the app/workers so they pick up `QDRANT_API_KEY`.
7. Stop the Drive listener, and keep it stopped until U10 is done.
8. The sandbox must reach `localhost:6333` and `localhost:7688` (host networking) for U1, U2 and U8.

**Done when:** the three curl codes are 401 / 200 / 403 and `pgrep -f drive_event_listener`
prints nothing.
